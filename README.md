# 🎓 Sistema de Gestão de Alunos

## 📌 Descrição do Projeto

Este projeto consiste no desenvolvimento de uma aplicação web para gerenciamento de alunos, permitindo o cadastro, edição, exclusão e visualização de informações acadêmicas.

A aplicação foi desenvolvida utilizando tecnologias web modernas, com foco em organização de dados e usabilidade.

---

## 🎯 Objetivo da Aplicação

O objetivo do sistema é facilitar o controle de alunos em uma instituição de ensino, permitindo:

* Cadastro de alunos
* Edição de informações
* Exclusão de registros
* Consulta de alunos cadastrados
* Organização por turma

---

## 🛠️ Tecnologias Utilizadas

* Node.js
* NestJS
* TypeORM
* MySQL
* EJS (Template Engine)
* Bootstrap

## 🚀 Como Executar o Projeto

1. Clonar o repositório:

```
git clone https://github.com/seu-usuario/seu-repositorio.git
```

2. Acessar a pasta:

```
cd seu-repositorio
```

3. Instalar as dependências:

```
npm install
ou
npm i
```

4. Configurar o banco de dados no arquivo `.env`

5. Executar o projeto:

```
npm run start:dev
```

6. Acessar no navegador:

```
http://localhost:3000
```

---

## 📂 Estrutura do Projeto

* `src/modules/aluno` → módulo principal de alunos
* `views/aluno` → páginas EJS
* `database` → configuração do banco
